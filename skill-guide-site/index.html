壹、安裝說明

建議：第一次安裝請使用電腦版 ChatGPT，操作會比較順利。
1下載 Skill 安裝檔並進入「外掛程式」

先下載本頁上方的 Skill Pack ZIP 檔，登入 ChatGPT 個人帳戶後，在左上角點選「外掛程式」。

2點選右上角「新增」

進入外掛程式頁面後，點選右上角的「新增」。

3選擇「建立外掛程式」

在選單中選擇「建立外掛程式」。

4點輸入框左方的「＋」

進入 Plugin Creator 對話後，點選左方的「＋」。

5上傳 Skill Pack ZIP

點選「新增相片與檔案」，選取剛才下載的 Skill Pack ZIP，按送出後，系統會開始安裝。

貳、使用說明

安裝完成後，可在 ChatGPT 對話中選取「召會翻譯專家」，再提供原文與翻譯需求。

1選取「召會翻譯專家」

開啟新對話，在輸入框鍵入「@召」，從選單選取「召會翻譯專家」。若找不到，請先確認已安裝、登入相同帳戶，並重新開啟對話。

2輸入原文並說明需求

最簡單的方式，是在前面寫「翻英文」、「翻法文」、「翻德文」等，後面貼上要翻譯的文字。

想更精準：建議一併說明「目標語言、使用場合、翻譯模式、輸出格式」。長篇內容可依篇章分批處理，並要求沿用前文術語。
範例：
請將以下中文翻成英文，供主日聚會朗讀。採用「聚會朗讀自然版」，保留召會專有用語，以中英對照呈現。
3依使用場合選擇翻譯模式
模式適用情境與重點
召會用語優先（預設）晨興、綱要、申言與交通稿；優先保持術語一致。
聚會朗讀自然版聚會中公開朗讀；保留原意與術語，調整語序。
書報語氣精準版書報與職事內容；保留論述架構及層次。
福音朋友易懂版福音接觸；降低句型難度，保留關鍵屬靈概念。
4上傳 Word、PDF 或試算表進行翻譯

若原文在 Word、PDF 或試算表中，可點輸入框旁的「＋」，選擇「新增相片與檔案」，再指定要翻譯的頁數、段落或工作表範圍。

範例指令：
請將附件第 1 至 3 頁翻成英文，採「召會用語優先」，保留標題及綱要編號，以中英逐段對照呈現。遇到無法辨識的文字請列出，不要猜譯。
5檢查結果並提出修訂

先核對有無漏譯、增譯，以及人名、經節、綱要層次和固定用語是否一致。

範例指令：
請保留原意，將英文調整為適合聚會朗讀的語氣。「神的經綸」本篇統一使用 God’s economy，並檢查全文一致性。
經文與正式引文：涉及恢復本經文或正式職事引文時，請提供可核對的原文及正式譯文；若缺少資料，應標示待確認，不宜把生成文字當作正式逐字引文。
6多語翻譯與對話練習

可指定英文、泰文、印尼文、德文、法文、日文、韓文、西班牙文或俄文等語言。不同語言的參考資料完整度不同；遇到尚未確認的固定譯名，可要求加上「術語備註」。

多語翻譯：
請把以下聚會通知翻成泰文與印尼文，保留人名、日期及地點，各語言分開呈現。
對話練習：
請用初級英文與我練習召會生活對話，每次只問一個問題。先讓我回答，一段練習後再整理值得改進的用字與文法。

參、Skill Pack 內建資料庫範例

下載並解壓縮 Skill Pack 後，可在 church-translation-expert/references/ 資料夾中找到資料庫範例檔。這些 CSV 檔不是另外安裝的資料庫服務，而是供 Skill 查考術語與中英對照語料的參考資料。

檔案內容與用途主要欄位
glossary.csv多語術語表範例。收錄「召會、那靈、神的經綸、申言、晨興聖言」等固定用語，協助翻譯時保持術語一致。部分語言欄位仍可依已複核資料繼續補充。source_zh、en、th、id、de、fr、ja、ko、es、category、note、verified
official-bilingual-corpus.csv中英平行語料範例。依訓練、篇次、綱要層級、頁碼與來源檔保存中英文對照，可供句型、綱要結構、上下文及既有譯法參考。id、training、message_no、record_type、structure、source_page、zh、en、source_file
使用提醒：若要自行擴充，請維持 UTF-8 編碼與原欄位名稱，先核對原文、譯文及來源，再將 verified 標記為已確認。正式經文與職事引文仍應以可核對的正式資料為準。

肆、資料庫擴充說明

技能資料庫包含術語表、正式例句與平行語料。擴充時，應先整理並複核資料，再更新外掛程式的參考檔與使用規則。

一、當次參考 vs. 正式擴充

當次參考：在一般翻譯對話中附上新術語表或中外文對照稿，只影響本次任務，不能據此認定技能資料庫已更新。

正式擴充：由有編輯權限的人進入外掛程式編輯流程，將已複核資料納入參考檔、更新指示並完成測試。

二、準備可核對的中外文資料

先備妥原文與經確認的對應譯文，保留書名或篇名、語言、段落編號及來源位置。綱要應依相同篇章及編號配對；術語表每列記錄一組術語及其用法。

資料類型建議保留欄位
術語對照原詞、目標語譯法、語言、語境、來源、複核狀態。
雙語句段原文、對應譯文、篇名、段落／綱要編號、來源。
多語綱要共同編號、中文／英文及目標語段落、出處、版本。
三、去重並複核內容

檢查句段是否完整、兩種語言是否對齊，以及術語是否與既有資料衝突。截斷、辨識錯誤或尚未確認的資料，先列為「待複核」，確認後再納入正式參考。

四、將資料納入外掛程式（重點）

進入 ChatGPT「外掛程式」，開啟可編輯的「召會翻譯專家」，選擇「編輯外掛程式」（Edit Plugin）。在更新對話中附上已複核資料，說明新增語言、內容及用途。

五、另開新對話驗證更新

完成後另開新對話，重新選取外掛程式，不附上剛才資料檔，測試新增術語、原有術語及尚未收錄的詞，確認是否能正確讀取參考資料。

六、保留版本並提供更新

保存更新前版本及測試結果；若需讓其他聖徒使用，提供更新後的外掛程式連結或安裝包，並請使用者另開新對話測試。

常見提醒

找不到 Skill？請確認使用同一個 ChatGPT 帳戶、已完成安裝，並重新開啟新對話。
找不到「外掛程式／建立外掛程式」？不同帳號與工作區的功能開放狀況可能不同。
正式經文與職事引文：請以可核對的正式資料為準，不要把模型自行生成內容當作官方逐字譯文。
